Form Routine Kit 개인정보처리방침

최종 수정일: 2026-09-21

1. 기본 원칙

Form Routine Kit은 이름, 전화번호, 주소, 이메일 등 이용자의 개인정보를 개발자 서버나 자체 데이터베이스로 수집·저장하지 않는 것을 원칙으로 합니다.

2. 브라우저에서의 처리

사용자가 추가한 JSON Kit과 실행을 위해 필요한 데이터는 이용자의 브라우저와 설치된 확장 프로그램에서 처리됩니다. 실행 로그는 현재 실행 화면에 표시하기 위한 목적으로 브라우저 내부에서 전달되며 개발자 서버로 전송·저장하지 않습니다.

3. GitHub Pages 호스팅

이 웹사이트는 GitHub Pages로 제공됩니다. GitHub는 GitHub Pages 방문자의 IP 주소를 보안 목적으로 기록·저장한다고 안내하고 있습니다. 이는 Form Routine Kit 개발자가 직접 수집·저장하는 데이터가 아니며, GitHub의 개인정보처리방침이 적용됩니다.

4. 웹사이트의 개인정보 처리

이 도구가 방문하거나 자동 입력하는 대상 웹사이트는 별도의 개인정보처리방침에 따라 이름, 연락처 등 개인정보를 수집할 수 있습니다. 대상 웹사이트의 처리에 대해서는 해당 웹사이트의 개인정보처리방침과 이용약관을 직접 확인해야 합니다.

5. 확장 프로그램 권한

확장 프로그램은 실행 시 필요한 대상 사이트에 대해서만 호스트 접근 권한을 요청하고, 작업이 끝나거나 중지되면 해당 호스트 권한을 제거하도록 동작합니다. 웹페이지를 읽고 정해진 Kit의 입력·선택을 수행할 수 있으므로 설치 및 실행 전에 권한 요청 내용을 확인해 주세요.

6. 로그

화면에 표시되는 로그에는 실행 상태와 대상 사이트의 출처·문항 처리 결과 등 기능 수행에 필요한 최소한의 정보만 표시합니다. 입력한 실제 이름·전화번호 등의 값 자체를 로그로 기록하지 않습니다.

7. 문의

개인정보 관련 문의는 GitHub 저장소의 공개된 연락 수단을 이용해 주세요.

8. 변경

서비스 기능이나 법령 변경에 따라 이 방침을 수정할 수 있으며, 변경 시 이 페이지의 최종 수정일을 갱신합니다.
