Form Routine Kit 개인정보처리방침

최종 수정일: 2026-09-21

1. 서비스의 목적

이 서비스는 공개된 이벤트의 이름, URL, 정답 등 이벤트 참여에 필요한 최소한의 정보를 정리하고 사용자가 정답을 복사할 수 있도록 돕습니다.

2. 개인정보 처리

공개 JSON Kit에는 이름, 연락처, 주소, 이메일, 계정 ID, 비밀번호, 인증코드 등 이용자를 식별하거나 인증에 사용할 수 있는 개인정보를 입력하지 않는 것을 원칙으로 합니다. 개발자는 이용자의 개인정보를 수집하기 위한 입력창이나 계정을 제공하지 않습니다.

3. 정답 작성 방법

이벤트 정답은 개발자가 이벤트 내용을 확인한 뒤 직접 작성합니다. 매크로, 브라우저 자동화, 대상 이벤트 페이지의 DOM 읽기 또는 자동 수집 기능으로 정답을 수집하지 않습니다. 공개 JSON에는 확인된 정답과 이벤트명·URL 등 서비스에 필요한 정보만 기록합니다.

4. 클립보드

사용자가 정답 복사 또는 이동 버튼을 직접 누르면 해당 정답을 시스템 클립보드에 쓰기만 합니다. 서비스는 사용자의 기존 클립보드 내용을 읽거나 서버로 전송하지 않습니다.

5. 외부 사이트

이 서비스의 이벤트 URL을 열면 이용자는 해당 외부 사이트로 이동합니다. 외부 사이트에서 이루어지는 개인정보 수집, 쿠키, 로그인, 응모 및 이용약관 적용은 해당 사이트의 정책에 따릅니다. 이 서비스는 외부 사이트에 자동으로 입력하거나 제출하지 않습니다.

6. 호스팅

웹사이트는 GitHub Pages에서 제공됩니다. GitHub가 호스팅 과정에서 처리하는 접속 정보에는 GitHub의 관련 정책이 적용됩니다.

7. 문의 및 변경

개인정보 또는 데이터 처리에 관한 문의는 공개된 GitHub 저장소의 연락 수단을 이용해 주세요. 서비스 구조가 변경되면 이 방침의 최종 수정일과 내용을 함께 갱신합니다.
