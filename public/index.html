Form Routine Kit

공개 Kit을 불러와 브라우저 확장 프로그램으로 실행합니다.

이용 전 확인

이 서비스는 이름과 연락처를 자체 서버로 전송하거나 개발자에게 수집하지 않습니다. 입력한 정보는 이용자의 브라우저에서 해당 설문 페이지에 입력하기 위한 용도로만 사용됩니다.

설문에 입력·제출된 개인정보는 이벤트 주최측 또는 설문에 명시된 제3자에게 제공될 수 있습니다. 각 설문의 개인정보 수집·이용 및 제3자 제공 내용을 직접 확인해 주세요.

확장 프로그램 설치

이 페이지는 앱이 아니라 웹페이지입니다. 자동 입력 기능을 사용하려면 Chrome/Edge에서 Form Routine Kit 확장 프로그램을 설치해야 합니다.

  1. GitHub 저장소에서 ZIP으로 다운로드합니다.
  2. 압축을 풀고 브라우저의 chrome://extensions에서 개발자 모드를 켭니다.
  3. ‘압축해제된 확장 프로그램을 로드’로 public/extension 폴더를 선택합니다.
  4. 설치 후 대상 설문 페이지에서 확장 프로그램을 실행합니다.

확장 프로그램이 없으면 이 웹페이지가 다른 사이트의 설문 내용을 직접 읽을 수는 없습니다.
