Form Routine Kit

공개 Kit을 불러와 브라우저 확장 프로그램으로 실행합니다.

이용 전 확인

이 서비스는 이름·전화번호·주소·이메일 등 개인정보를 개발자 서버나 자체 데이터베이스로 수집·저장하지 않습니다.

JSON Kit과 실행 로그는 브라우저 안에서 처리됩니다. 대상 이벤트 사이트가 직접 처리하는 개인정보는 해당 사이트의 개인정보처리방침을 확인해 주세요.

확장 프로그램은 실행할 때 대상 사이트의 호스트 접근 권한을 요청하며, 작업 종료 또는 중지 후 해당 권한을 제거합니다. 실행 중에는 웹페이지를 읽고 정해진 Kit의 입력·선택을 수행할 수 있습니다.

확장 프로그램 추가 방법

확장 프로그램 ZIP 다운로드

  1. ZIP 파일을 다운로드합니다.
  2. ZIP 파일의 압축을 풉니다.
  3. Chrome 주소창에 chrome://extensions를 입력합니다.
  4. 오른쪽 위 개발자 모드를 켭니다.
  5. 압축해제된 확장 프로그램을 로드를 누릅니다.
  6. 압축을 푼 확장 프로그램 폴더를 선택합니다.
